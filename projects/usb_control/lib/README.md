The usb/device Python modules are copied unchanged from MicroPython's
micropython-lib at commit 90028be0829c6e988b5e239b28f39fb91b6b20e2:

https://github.com/micropython/micropython-lib/tree/90028be0829c6e988b5e239b28f39fb91b6b20e2/micropython/usb

Packages: usb-device 0.2.1, usb-device-hid 0.2.0, usb-device-keyboard 0.1.1.
These modules carry MIT license notices naming Angus Gratton. The upstream
MIT license text is in LICENSE.micropython-lib. No host Python dependency
installation is needed; these modules are deployed to the Pico's /lib/usb/device.
