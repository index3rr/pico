# pi pico w scripts

this is a repo for my pi pico w scripts which may be of use to someone who wants to do the following things:

- host a tor relay (not really, but essentially an ip that acts like one if you point your tor at it, useful for allowing someone behind a firewall onto tor)
- wake their computer on lan using a magic uuid 
- an example of discord webhooks on the pico

make sure you rename example_secrets.py to secrets.py and fill in some secrets
